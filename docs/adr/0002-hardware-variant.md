# ADR 0002: Variante de hardware — SX1262 915MHz

## Contexto
T-Watch S3 é vendido com SX1262 (433/868/915/920MHz), SX1280 (2.4GHz) ou CC1101.

## Decisão
Comprar a variante **SX1262 915MHz**.

## Consequências
- Conformidade com a faixa 915–928 MHz regulada pela Anatel para LPWAN no Brasil.
- Compatível com o padrão Meshtastic nas Américas.
- Máximo alcance de LoRa entre as opções.
